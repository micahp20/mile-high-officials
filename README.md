# Mile High Officials

Public website for [Mile High Officials](https://www.milehighofficials.com/), a 501(c)(3) nonprofit (EIN 45-5183098) that recruits, trains, mentors, and assigns sports officials in Colorado. Pages are generated by `python3 _generate.py`.

This repo is a mobile-first static site with a contact form. It is a rebuild of the previous Google Sites site. 

## Local preview

Any static server from the project root works, for example:

```bash
npx serve .
```

The contact form on `/contact-us/` is submitted with AJAX to [FormSubmit](https://formsubmit.co). After a successful submission, visitors are sent to `/thank-you/`. No API key is required. The first submission sends an activation email to `admin@milehighofficials.com`; later submissions are delivered to that inbox.

## Contact form email

Submissions are emailed to `admin@milehighofficials.com` through FormSubmit. The form includes a honeypot field and shows an on-page success or error message. The form uses FormSubmit's random alias in the endpoint so the inbox address is not visible in the page source.

## Theme

Every page has a light/dark toggle in the header. The choice is stored in `localStorage` under `mho-theme`. If the visitor has not chosen yet, the site follows the system color scheme.

## Official application

`/apply/` posts (multipart) to the Vercel function `api/apply.mjs`, which:

1. Rejects bots quietly (honeypot `_honey` plus a minimum fill time) and validates the answers.
2. Saves the application, and any résumé (PDF/DOC/DOCX, up to 4 MB), to the separate Supabase project `mho-applications` (tables `applications` and `application_resumes`) through token-checked database functions. The tables are not readable with the public key.
3. Emails the answers to `admin@milehighofficials.com` through the same FormSubmit endpoint as the contact form, with a private résumé download link (`/api/resume`, signed). If that email fails, the browser sends it as a fallback.

Viewing applications: `/api/applications?key=<MHO_VIEW_KEY>` lists them (mobile-friendly) with résumé links, and `&format=csv` downloads a spreadsheet. They can also be viewed and edited (Status, Notes) in the Supabase Table Editor.

Vercel environment variables: `MHO_SUPABASE_URL`, `MHO_SUPABASE_KEY`, `MHO_DB_TOKEN`, `MHO_LINK_SECRET`, `MHO_VIEW_KEY`.

The main phone number for Call buttons is the `MHO_PHONE` constant in `_generate.py` (empty hides the Call button on sport pages).
